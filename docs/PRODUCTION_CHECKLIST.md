# Checklist avant publication

- [ ] Compte administrateur créé dans Neon Auth.
- [ ] Adresse administrateur ajoutée à `ADMIN_EMAILS` dans Vercel.
- [ ] `NEON_AUTH_COOKIE_SECRET` configuré avec une valeur différente par environnement.
- [ ] `NEXT_PUBLIC_WHATSAPP_NUMBER` configuré dans Development, Preview et Production.
- [ ] Catégories et produits de Nova Commerce validés dans la base Neon.
- [ ] Stockage objet et permissions d'upload vérifiés si les médias sont utilisés.
- [ ] `npm run lint`, `npm run typecheck`, `npm run test`, `npm run build` et `npm audit` réussis.
- [ ] Vérification mobile, clavier, contraste et liens WhatsApp effectuée.
- [ ] Mentions légales et textes commerciaux validés par le propriétaire.
- [ ] Validation humaine explicite avant domaine, DNS et publication Production.
